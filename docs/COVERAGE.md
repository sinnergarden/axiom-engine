## Decisions and unresolved scope

- Sequential single-assignment nodes keep pre-winsorized inputs available; output names are explicit aliases. No business formulas are eval-ed or built into Core.
- Shift and finite rolling declare sessions versus observations, window/min_periods and current endpoint. Full history closure is derived additively; partial warmup must be explicit.
- R0 ret_20/60/120 uses unspecified legacy pandas fill defaults. E0 supports explicit `fill_method=none`; a Research release must resolve/version the policy before lowering these real definitions. No silent equivalence claim.
- Industry missing/excluded zero masking differs from normal CS outputs. Explicit policies preserve both branches; no implicit all-row reference fallback.
- Stable cumulative-to-quarter/TTM/revision preparation stays Data. Fixed event columns can include Data-prepared predecessor facts. Core as-of never selects source revisions.
- Model center/scale, model inference, PredictionFrame, SignalFrame, SignalPlan and signal orchestration are PR2.
- All 24 R0 UNKNOWN objects are retained in tests/fixtures/r0_unknowns.json, including nested Feature/PIT blockers. PR1 cannot settle full CORE_ABI or Data/PIT/OOS obligations.
